## How to Use
1. Download or clone this repository to your computer.
2. Open a case-study folder.
3. Open `program.py` in Python IDLE, VS Code, or another Python editor.
4. Run the program.
5. Enter the requested values in the terminal/console when prompted.

### Run from a terminal
From inside a case-study folder, run:
```bash
python program.py
```
If your system uses the `python3` command, run:
```bash
python3 program.py
```
